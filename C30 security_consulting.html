01
COMPLIANCE · 컴플라이언스
보안 컴플라이언스 컨설팅
SECURITY COMPLIANCE CONSULTING

국내 ISMS · ISMS-P, 국제 ISO/IEC 27001 · 27701까지 — 정보보호 관리체계 인증 취득과 유지관리 전 과정을 지원합니다. 단순 인증 통과가 아닌, 실질적 보안 수준 향상이 목표입니다.

ISMS ISMS-P ISO 27001 ISO 27701
관리체계 인증 컨설팅 — Management System Certification

국내외 대표 정보보호 관리체계 인증 취득을 위한 전 과정 컨설팅을 수행합니다. 갭 분석부터 심사 대응, 인증 후 유지관리까지 스틸리언이 함께합니다. 현업 영향을 최소화하여 실질적 보안 체계를 구축합니다.

KISA ISMS-P 정보보호 및 개인정보보호 관리체계 인증
KISA ISMS 정보보호 관리체계 인증
ISO/IEC 27001 국제 정보보호 관리체계 표준(정보 보안 경영 시스템)
ISO/IEC 27701 개인정보 관리체계 국제 표준(개인정보 관리 시스템)
Gap Analysis 인증 기준 대비 현재 수준 진단
심사 대응 인증 심사원 대응 및 결함 조치
사후관리 연간 유지관리 및 갱신 심사 대응
02
VULNERABILITY · 취약점 진단
보안 취약점 진단 컨설팅
VULNERABILITY ASSESSMENT CONSULTING

주요정보통신기반시설, 전자금융기반시설, 클라우드 환경의 취약점을 최신 기준으로 진단하고, 인프라 전반의 기술적 취약점을 체계적으로 식별하여 개선 방안을 제시합니다.

주요정보통신기반시설 기반
취약점 분석·평가 컨설팅
VULNERABILITY ANALYSIS & ASSESSMENT

주요정보통신기반시설, 전자금융기반시설, 클라우드 환경의 취약점을 각각의 최신 기준으로 진단합니다. 정부 고시 기준, 금융보안원 기준, 클라우드 환경별 보안 기준을 종합 적용하여 체계적인 취약점 평가를 수행합니다.

주요정보통신기반시설 — 최신 과학기술정보통신부 고시에 따른 기준으로 취약점 분석·평가
전자금융기반시설 — 금융보안원에서 공표한 최신 기준으로 보안 취약점 평가
클라우드 취약점 진단 — AWS · Azure · GCP IAM · 네트워크 · 저장소 구성 진단
03
STRATEGIC · 종합 컨설팅
종합 보안 컨설팅
COMPREHENSIVE SECURITY CONSULTING

중장기 보안 로드맵 수립, 실전형 해킹 메일 훈련, 그리고 맞춤형 실무 교육까지 — 기업의 보안 문화와 체계를 근본적으로 끌어올리는 전략 컨설팅 서비스입니다.

ROADMAP

CUSTOM SECURITY TRAINING

직무와 업무 환경에 최적화된 맞춤형 실무 교육을 제공합니다. 임원·개발자·인사담당자·일반 임직원 등 대상별 커리큘럼으로, 실제 위협 사례와 실습 기반의 몰입형 교육을 수행합니다.

개인정보보호 컨설팅
PRIVACY CONSULTING

개인정보보호법 개정과 강화되는 규제 환경 속에서, 기업의 개인정보 생애주기 전반과 위·수탁 관계까지 아우르는 실질적 개인정보 거버넌스를 설계합니다.

LIFECYCLE

개인정보 생애주기(수집·이용·보관·제공·파기) 각 단계별 법적 요구사항과 기술적·관리적 보호조치를 종합 점검합니다. 법률 대응과 기술 구현을 동시에 설계하여, 현업에서 즉시 적용 가능한 실천 지침을 제공합니다.

수집·이용 — 동의 설계, 수집 최소화, 목적 명확화
보관·관리 — 암호화, 접근통제, 접속기록 관리

자주 묻는 질문
컨설팅 기간은 얼마나 걸리며, 중소기업도 컨설팅을 받을 수 있나요?
+
컨설팅 기간은 대상 범위, 자산 규모, 진행 목적(인증 취득·취약점 진단·종합 컨설팅 등)에 따라 달라집니다. 단일 인증 컨설팅(ISMS 등)은 보통 3~6개월, 종합 보안 컨설팅의 경우 6개월 이상이 일반적이며, 정확한 일정은 사전 Scoping 단계에서 협의해 확정합니다.
중소기업도 충분히 컨설팅 대상이 됩니다. 오히려 보안 인력·예산이 제한된 중소기업일수록 STL-CSCM 방법론에 따른 우선순위 기반 컨설팅이 더 효과적입니다. 기업 규모와 보안 성숙도에 맞춰 진단 범위와 기간을 조정해 합리적인 비용으로 실질적 보안 수준 향상을 지원합니다.
컨설팅 결과물은 어떻게 제공되며, 클라우드 환경도 진단 가능한가요?
+
컨설팅 결과는 공식 보고서 형태로 제공되며, 위험 분석 결과·취약점 목록·심각도·즉시 적용 가능한 개선 가이드·중장기 보안 로드맵을 포함합니다. 경영진용 요약 보고서와 실무자용 상세 기술 보고서를 분리해 제공하며, 인증 심사 대응이 필요한 경우 ISMS-P·ISO 27001 등 심사에 그대로 활용 가능한 형태로 정리해 드립니다. 필요 시 결과 브리핑과 Q&A 세션도 함께 진행합니다.
클라우드 환경 진단도 핵심 영역 중 하나입니다. AWS·Azure·GCP 등 주요 클라우드 콘솔, 서버, 네트워크 장비, 데이터베이스, 정보보호 시스템, PC 등 다양한 자산을 대상으로 기술 취약점 점검을 수행하며, 주요정보통신기반시설 취약점 분석·평가 기준 등 국내 규제와 클라우드 보안 모범사례(CIS Benchmark 등)를 함께 적용합니다.
작년에 받은 보안 점검 보고서가 있는데, 올해도 진단이 필요한가요?
+
기존 점검 보고서는 컨설팅 시작 시점의 중요한 입력 자료가 됩니다. 사전 검토 단계에서 작년 보고서를 함께 분석해 이미 파악된 위험·조치 완료 항목·잔여 리스크를 식별하고, 중복 점검을 최소화한 효율적인 컨설팅 범위를 설계합니다.
