왜 AppSuit Air인가

개발 공수를 늘리지 않으면서 전문가급 보안을 즉시 적용할 수 있는 클라우드 보안 솔루션입니다.
구축형(Premium)과 동일한 보안 엔진 위에서 도입 방식만 가볍게 만든 제품입니다.

도입 즉시 보안 적용 — 개발 공수 최소화
SDK 연동·빌드 환경 수정 없이, APK / IPA 업로드만으로 보안이 적용됩니다.
개발팀의 추가 작업이 거의 없습니다.
클라우드형 — 인프라 구축 없이 사용
100% 클라우드 기반 SaaS로 동작하여 별도의 서버 설치나 온프레미스 환경이 필요 없습니다.
자동 OS 대응 + 유지보수 포함
새로운 OS 버전 출시 시 자동 업데이트가 적용되며, 기술 지원 및 유지보수가 구독에 포함됩니다.
AppSuit Premium 동일 보안 엔진 — GS 1등급
구축형 Premium과 동일한 GS 인증 1등급 보안 엔진을 사용합니다.
도입 방식의 차이일 뿐, 보안 수준은 동일합니다.

자주 묻는 질문
AppSuit Air는 어떤 OS와 개발 환경을 지원하나요?
+
Android 5.0(API 21) 이상, iOS 11 이상을 지원하며 C·JAVA·Kotlin·Swift·Objective-C 등 주요 언어와 함께 Flutter·React Native 등 하이브리드 환경도 지원합니다.
100% 클라우드 기반(SaaS)으로 동작하므로 별도의 On-Premise 환경 구축은 필요하지 않으며, 서버 업로드 방식이라 개발 환경에 보안 라이브러리를 직접 추가할 필요도 없습니다.
기존 보안 솔루션이나 타사 SDK와 충돌이 발생하지 않나요?
+
AppSuit Air는 앱 보호 및 모니터링 기능을 클라우드에서 처리하므로 타사의 모바일 백신, 가상 키패드, 보안 SDK 등과 충돌 없이 안정적으로 함께 동작합니다.
또한 Radar 모듈을 통해 외부 솔루션과 연계된 공격 데이터도 통합 분석할 수 있어, 기존 보안 자산을 그대로 유지하면서 Air를 추가 도입할 수 있습니다.
라이선스 정책과 도입 절차는 어떻게 되나요?
+
AppSuit Air는 클라우드 구독형 서비스로, 월간 / 연간 단위로 제공되며 유지보수 및 기술 지원이 구독에 포함됩니다.
App 단위로 과금되며, 사용량 및 모니터링 범위에 따라 요금제가 구분됩니다.
도입 절차는 문의를 주시면 담당자가 환경 및 보안 옵션 안내와 견적을 제공하고, 이후 솔루션 검증(POC) 단계를 통해 적용 적합성을 확인한 뒤 구독 계약을 진행하는 흐름입니다.
