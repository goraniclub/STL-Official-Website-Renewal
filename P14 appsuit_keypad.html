입력 데이터를 보호하는 보안 동작 구조

AppSuit Keypad는 입력 순간부터 전송까지 데이터가 노출되지 않도록 보호 구조를 설계합니다.

입력 처리 대응
STEP 01 입력 보호 단계
입력 단계에서의 탈취 차단
사용자가 입력하는 순간, 터치 좌표를 변환하여 동일 입력도 내부적으로 다른 값으로 처리됩니다.
  • 입력값 직접 노출 방지
  • 키로깅 및 화면 기반 탈취 차단
STEP 02 데이터 보호 단계
입력 데이터 암호화 처리
입력된 값은 즉시 암호화되며, 단말 내부 및 전송 과정에서 복호화 없이 보호됩니다.
  • 입력값 실시간 암호화
  • 네트워크 구간 데이터 보호
STEP 03 공격 대응 단계
입력 패턴 기반 공격 무력화
키패드 배열을 동적으로 변경하여 입력 패턴 분석 및 자동화 공격을 차단합니다.
  • 랜덤 / 삽입형 키 배열 지원
  • 패턴 분석 공격 대응

자주 묻는 질문
AppSuit Keypad는 어떤 OS와 개발 환경을 지원하나요?
+
Android·iOS 모바일 앱과 JavaScript 기반 웹 환경을 모두 지원합니다.
Android·iOS는 커스텀 뷰 형태로 제공되며, 웹 환경에서는 JavaScript 라이브러리로 동일한 입력 보안 기능을 적용할 수 있습니다.
숫자 PIN, 쿼티(Qwerty) 등 서비스 특성에 맞는 레이아웃을 함께 제공하며, 시각 장애인을 위한 접근성 기능도 포함되어 있습니다.
금융보안원·행정안전부 가이드라인 준수 여부를 공식적으로 확인할 수 있나요?
+
금융위원회 전자금융감독규정 제15조의 '키보드 해킹 방지 프로그램', 금융보안원 스마트폰 전자금융서비스 보안 가이드의 '가상 키패드 사용', 행정안전부 모바일 전자정부 서비스 관리 지침의 '보안 키패드 적용', 개인정보보호위원회 개인정보 보호법 제29조의 '개인정보 보호 안전조치' 등 주요 규제의 입력 구간 보호 요구 항목을 충족합니다.
또한 한국정보통신기술협회(TTA)의 GS(Good Software) 인증 1등급 및 가상 보안 키패드 생성 기술 특허(KIPO)를 보유하여 도입 검토 시 공식 준수 문서를 제공해 드립니다.
키패드 UI나 기능을 자유롭게 커스터마이징 할 수 있나요?
+
브랜드 이미지에 맞게 UI와 버튼 기능을 자유롭게 변경할 수 있습니다.
적용 방식은 SDK·라이브러리 형태로, 클라이언트용 라이브러리와 WAS 서버용 모듈(Jar)을 함께 제공합니다. 가이드 문서와 샘플을 참고하여 개발 환경에 라이브러리를 추가한 뒤, 기능 및 레이아웃을 커스터마이징하여 적용하는 흐름입니다.
키 배열은 순차·무작위·공백 배열을 정책에 맞게 선택할 수 있어, 보안 수준과 사용 편의성을 함께 조정할 수 있습니다.
